# 🧠 AI-Augmented Engineering Mental Model

## Core Principle

> **Think just enough → Build fast → Verify deeply → Iterate**

---

## ⚡ Workflow Loop

1. **🧭 Quick Thinking (2–10 min)**

   * What is the actual problem?
   * Inputs / outputs?
   * Where does this fit in the system?
   * Any constraints?

2. **⚡ Build with AI**

   * Generate baseline solution
   * Explore approaches
   * Scaffold quickly

3. **🔍 Critical Verification**

   * Does this *actually* solve the problem?
   * What edge cases are missing?
   * Does it fit system design?
   * Is it overcomplicated?

4. **🔁 Iterate**

   * Refine prompts
   * Refactor code
   * Simplify + improve

---

## 🧪 Debugging Playbook

**Before AI:**

* Is it DB, network, or CPU?
* Affects all users or specific cases?
* Any logs or metrics?

**With AI:**

* “Here’s my code + context, where are bottlenecks?”

**After AI:**

* Add logs
* Measure latency
* Confirm hypothesis

> ⚠️ Never trust AI without verification

---

## 🧭 Think vs Act Heuristic

### 🧠 Think More When:

* Designing systems
* Making architecture decisions
* Requirements are unclear
* Code is critical / high-risk

### ⚡ Act Fast When:

* Small features
* Known patterns
* Refactoring
* Experimentation

---

## 🧠 High-Value Engineer Traits

* Questions AI output
* Understands systems, not just code
* Strong at debugging
* Sees edge cases
* Owns outcomes

---

## 🤖 AI Usage Rules

* Use AI to **accelerate**, not replace thinking
* Treat AI like a **fast but unreliable junior**
* Always:

  * Review
  * Test
  * Validate

---

## 💡 Golden Rules

* Don’t overthink → you’ll stall
* Don’t autopilot → you’ll break things
* **Switch between thinking and doing deliberately**

---

## 🧭 One-Liner to Remember

> **Intent → AI → Judgment → Iteration**
