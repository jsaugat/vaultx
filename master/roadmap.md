## Full Roadmap — Germany Masters Prep

### Right Now → Month 1: Foundation + Language Start
**Tech**
- Core Java — OOP, collections, exception handling
- Small logic programs, no web yet
- 30 mins Leetcode easy daily — just for logic muscle

**Languages**
- Start German immediately — A1, use Duolingo just to begin but pair it with a structured course like Deutsche Welle (free) or Goethe Institut online
- Start IELTS prep in parallel — diagnose your current level first, take a free mock test

---

### Month 2: Backend Basics + Language Consistency
**Tech**
- Spring Boot basics
- Build your first REST API with proper layered architecture
- Learn PostgreSQL raw SQL first, then Spring Data JPA

**Languages**
- German: Push to finish A1 solidly
- IELTS: Focus on your weakest section (usually Writing for Nepali students)

---

### Month 3: Real Backend + Applications Begin
**Tech**
- Add authentication, error handling, logging to your project
- Read real open source Spring Boot projects on GitHub daily
- Learn basic Docker — German employers love this even at junior level

**Languages**
- German: A2 territory
- IELTS: Take a full mock test, identify gaps, fix them

**Masters Applications**
- Shortlist 5–7 German universities
- Start SOP (Statement of Purpose) draft
- Get transcripts, recommendation letters moving — these take time in Nepal

---

### Month 4: Serious Project + IELTS Exam
**Tech**
- Build one real project — multi-module, clean architecture, real complexity
- Examples that impress German employers:
  - Inventory management system
  - Expense tracker with multi-user auth
  - Simple booking system
- Push everything to GitHub with proper README

**Languages**
- IELTS: Sit the actual exam — target 6.5 minimum, 7.0 is better
- German: Solidify A2, begin B1

---

### Month 5–6: Polish + Apply
**Tech**
- Refine your project, add tests (JUnit — Germans care about testing)
- Start applying to Werkstudent roles on LinkedIn, Indeed.de, StepStone.de — even remotely from Nepal to build interview confidence

**Applications**
- Submit university applications
- German: Keep pushing toward B1 — even partial B1 before arrival is valuable

---
