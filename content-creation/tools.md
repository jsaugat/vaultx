# Motion Graphics Explainer Video — Tool Stack

Tools required to create minimal 2D documentary / motion graphics explainer videos.

---

## Core tools

**Adobe After Effects**
- main animation + compositing tool
- used for motion graphics, typography, transitions, scene assembly

**Adobe Illustrator**
- vector asset creation (icons, maps, shapes)
- keeps graphics scalable and clean for animation

**Figma (optional)**
- storyboard planning
- layout composition
- quick visual mockups before animation

---

## Audio tools

**Audacity (free)** OR **Adobe Audition**
- voiceover recording
- noise reduction
- audio cleanup and leveling

---

## Asset sources (not creation tools)

Icons:
- **Noun Project**
- **Flaticon**
- **Icons8**

Maps:
- **SVG world maps** (editable in Illustrator)

Sound effects:
- **mixkit.co**
- **freesound.org**

Music:
- **YouTube Audio Library**

---

## Optional advanced tools (not needed initially)

**Blender** / **Cinema 4D**
- 3D animation (not required for current style)

After Effects plugins (Trapcode, etc.)
- particle systems, advanced effects (skip for now)

AI video tools
- not reliable for structured motion design workflow

---

## Minimal stack summary

Motion Design Pipeline:
```md
**Adobe After Effects**
├── Animation + compositing
│
**Adobe Illustrator**
├── Vector assets (icons, maps, shapes)
│
**Audio Tool (Audacity / Adobe Audition)**
├── Voiceover + sound cleanup
│
Asset Libraries
├── Icons / Maps / SFX / Music
│
(Optional)
**Figma**
├── Storyboard + layout planning
```
